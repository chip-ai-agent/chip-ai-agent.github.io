# chip-ai-agent.github.io

Bilingual (English / 中文) site for chip-ai-agent, served by GitHub Pages at https://chip-ai-agent.github.io.

## Edit

- Site text (title, intro, about, nav labels): `content/site.json`, one block per language.
- Add a research post: copy `content/posts/_example/` to `content/posts/<slug>/`, edit
  `meta.json` (date, tags, summary; set `"draft": false`), `en.md` and `zh.md`
  (the first `# ` line is the title).
- Rebuild, then commit and push:

```bash
pip install markdown
python3 build.py
```

`index.html`, `zh/` and `research/` are generated by `build.py`; don't edit them by hand.
English lives at `/`, Chinese at `/zh/`; every page links to the other language.

## PCBRouteAgent research note

- English: `/research/pcbrouteagent/`
- Chinese: `/zh/research/pcbrouteagent/`
- Text and author metadata: `content/posts/pcbrouteagent/`
- Latest manuscript PDF, task/method figures, and case-study images: `assets/research/pcbrouteagent/`
  (see its README for replacement instructions).

Research posts support optional `authors`, `affiliations`, bilingual `author_note`,
and bilingual resource `links` in `meta.json`. The contents sidebar is generated
from the article headings.

The routing-quality explorer reads `assets/research/pcbrouteagent/routing-results.json`.
Its data are transcribed from the paper's four main tables; D2/D3-A/D3-B rule-based
baselines link to PCBWorld v4, Table 22. Use `<!-- ROUTING_COMPARISON -->` in the
article source to render the bilingual controls and chart. Update the JSON and
rebuild when routing results change.
