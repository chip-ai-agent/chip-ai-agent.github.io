# chip-ai-agent.github.io

Bilingual (English / 中文) site for chip-ai-agent, served by GitHub Pages at https://chip-ai-agent.github.io.

## Edit

- Site text (title, intro, about, nav labels): `content/site.json`, one block per language.
- Add a research post: copy `content/posts/_example/` to `content/posts/<slug>/`, edit
  `meta.json` (date, tags, summary; set `"draft": false`), `en.md` and `zh.md`
  (the first `# ` line is the title).
- Rebuild, then commit and push:

```bash
pip install markdown
python3 build.py
```

`index.html`, `zh/` and `research/` are generated by `build.py`; don't edit them by hand.
English lives at `/`, Chinese at `/zh/`; every page links to the other language.
